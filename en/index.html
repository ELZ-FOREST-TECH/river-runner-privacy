River Runner Privacy Policy

Effective date: May 4, 2026

River Runner is an offline game with no user account registration. The app stores gameplay progress locally on the device and uses the Yandex Mobile Ads SDK to show banner ads.

Data Used by the App

The app stores only local gameplay progress on the device:

  • best run score;
  • total collected carrots;
  • selected character skin.

This data is used for gameplay and is not sent to the developer.

Advertising and Third-Party Services

The app uses the Yandex Mobile Ads SDK to display ads. When ads are delivered, the ad provider may process technical data needed for ad delivery, security, and measurement, for example:

  • device advertising identifiers;
  • IP address and basic device/OS metadata;
  • ad impression and click events;
  • SDK diagnostic data.

This processing is performed by the ad provider under its own policies. See:

  • Yandex Privacy Policy
  • Yandex Mobile Ads SDK

Sharing With Third Parties

The developer does not sell personal data. Data sharing with third parties is limited to what is required for the advertising SDK to operate.

Device Permissions

The app does not request camera, microphone, contacts, photos, or user file access. Network access is used to load ad content.

Children

If the app is used by children, parental supervision is recommended. For data and ad-related requests, use the contact below.

Deleting Data

Gameplay progress can be deleted by uninstalling the app. The app does not create accounts, so no separate account deletion request is required.

Contact

For privacy-related questions, contact: aokruan@gmail.com
