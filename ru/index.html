Политика конфиденциальности River Runner

Дата вступления в силу: 4 мая 2026 г.

River Runner — офлайн-игра без регистрации аккаунта. Приложение хранит прогресс локально на устройстве и использует рекламный SDK Yandex Mobile Ads для показа баннеров.

Какие данные использует приложение

Локально на устройстве сохраняются:

  • рекорд заезда;
  • общий баланс морковок;
  • выбранный скин персонажа.

Эти данные нужны для работы игры и не отправляются разработчику.

Реклама и сторонние сервисы

В приложении используется Yandex Mobile Ads SDK для показа рекламы. При показе рекламы сторонний рекламный провайдер может обрабатывать технические данные, необходимые для доставки, защиты и измерения рекламы, например:

  • рекламные идентификаторы устройства;
  • IP-адрес и базовые сведения об устройстве/ОС;
  • события показа/клика рекламы;
  • диагностические данные SDK.

Обработка таких данных выполняется на стороне провайдера рекламы по его правилам. Подробнее:

  • Политика конфиденциальности Яндекса
  • Yandex Mobile Ads SDK

Передача данных третьим лицам

Разработчик не продает персональные данные пользователей. Передача данных третьим лицам ограничена случаями, когда это необходимо для работы рекламного SDK.

Разрешения устройства

Приложение не запрашивает доступ к камере, микрофону, контактам, фотографиям или файлам пользователя. Сетевой доступ используется для загрузки рекламных материалов.

Дети

Если приложением пользуется ребенок, рекомендуем использование под контролем родителей. Для запросов по данным и рекламе используйте контакты ниже.

Удаление данных

Локальный игровой прогресс удаляется при удалении приложения с устройства. Отдельный запрос на удаление аккаунта не требуется, так как аккаунты не используются.
